# Authoritative Legal Data Sources for Smart Charter AI RAG

## 1. United States (USA)
*   **SEC EDGAR Database**: The primary source for material contracts filed by public companies.
    *   **Direct API**: [data.sec.gov](https://data.sec.gov/) provides RESTful access to JSON-formatted filings data [1].
    *   **Developer Toolkit**: [SEC EDGAR API Development Toolkit](https://api.edgarfiling.sec.gov/) for programmatic access to millions of corporate filings [2].
    *   **Third-Party APIs**: [SEC-API.io](https://sec-api.io/) offers a more developer-friendly gateway to search and stream SEC filings since 1993 [3].

## 2. United Kingdom (UK)
*   **Legislation.gov.uk**: The official home of UK legislation.
    *   **Legislation API**: Provides access to the statute book in XML, JSON, and YAML formats [4].
    *   **OpenAPI Documentation**: [legislation.gov.uk/openapi](https://www.legislation.gov.uk/openapi) details the Search and Document APIs for downloading statutes and statutory instruments [5].
    *   **Developer Zone**: [legislation.gov.uk/developer](https://www.legislation.gov.uk/developer) offers guidance on re-using consolidated UK legislation [6].

## 3. European Union (EU)
*   **EUR-Lex**: The gateway to European Union law.
    *   **EUR-Lex Webservice**: Allows registered users to query EUR-Lex directly via SOAP/XML [7].
    *   **REST API (Third-Party)**: [LexAPI](https://www.lex-api.com/) provides a professional REST API for European legal documents and case law [8].
    *   **Open Data Portal**: [EUR-Lex Open Data](https://eur-lex.europa.eu/content/help/data-reuse/reuse-contents-eurlex-details.html) for re-using data free of charge under specific copyright conditions [9].

## 4. South Africa (RSA)
*   **Laws.Africa**: A comprehensive collection of machine-readable African legislation.
    *   **Content API**: [laws.africa/api](https://laws.africa/api/) provides legislative content and metadata in Akoma Ntoso XML and other formats [10].
    *   **Developer Guide**: [developers.laws.africa](https://developers.laws.africa/get-started/overview) for detailed instructions on fetching South African legislation [11].
*   **Open Gazettes South Africa**: The largest freely available collection of government gazettes.
    *   **Data Portal**: [opengazettes.org.za](https://opengazettes.org.za/) and its [GitHub repository](https://github.com/OpenUpSA/opengazettes) provide access to indexed gazettes stored in S3 [12].
